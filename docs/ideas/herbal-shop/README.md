## 玩法對應

方劑的「類方加減」系譜正好對應「中間產物再合成」：

```
人參 + 白朮 + 茯苓 …… + 甘草 → 四君子湯
四君子湯 + 陳皮 → 異功散
異功散 + 半夏 → 六君子湯
六君子湯 + 木香 + 砂仁 → 香砂六君子湯
四君子湯 + 四物湯 → 八珍湯
八珍湯 + 黃耆 + 肉桂 → 十全大補湯
```

- 2～3 味的真實方劑可直接對應現有引擎：芍藥甘草湯、左金丸、佛手散、生脈散、玉屏風散、四逆湯等。
- 4 味以上的方劑：把 `game.yaml` 的 `slots`／`maxInputs` 調到 4～5，或透過中間方劑分段合成。
- **十八反、十九畏**可設計成「配伍禁忌」（比一般「無反應」更有戲劇性的失敗）。
- 配方紀錄每方附出處（如《傷寒論》），並引用《湯頭歌訣》原句作朱批。
